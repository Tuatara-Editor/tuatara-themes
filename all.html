themes Manual

for Tuatara 0.90.28 and later, every chapter on one page

This manual is written with modal editing on, first and foremost. Where a command also has a key that works with modal editing off, it is given as well, as the non-modal key.

What themes is

A package of popular colour themes for Tuatara, each a dark or light version of a palette you may know from other editors.

The package has fifteen themes. Each is chosen by its name, which M-x load-theme and (load-theme 'NAME) take.

It is a package, not part of the editor, and it needs no program.

1.1 Trying a theme

Once the package is loaded, M-x load-theme lists every theme, these included, and applies the one you choose. To have one at every start, put it after the package line in the init file:

(load-package "themes" :source "https://github.com/Tuatara-Editor/tuatara-themes")
(load-theme 'catppuccin-mocha)

1.2 A light and a dark theme

A pair of a light and a dark theme is what toggle-light-dark-theme switches between, and what the window follows when it follows the desktop's light or dark style:

(setf *dark-theme* 'tokyo-night
      *light-theme* 'tokyo-night-light)

Your own set-face lines in the init file stay on top of any theme. Chapter 4 lists the commands and settings.

What a theme covers

Which faces a theme colours, where the syntax colours come from, and how the contrast is checked.

2.1 The faces

Every theme is made for the faces that Tuatara's own ao-dark theme colours, so no face is left in the colours of another theme. That is text, the mode line, selections, searches, completion, lists, diffs, diagnostics, Org, the calendar and every syntax face.

A theme is a palette, as its project publishes it, and the roles that Tuatara's faces take from it. A role the theme does not name is made from the roles it does. Shades that the projects do not publish, such as the ground of an added line, are mixed from the theme's own colours.

2.2 The syntax colours

They follow each project's own editor port:

  • Catppuccin and Rose Pine: the Neovim themes;
  • Dracula, Nord, One Dark, Solarized and Everforest: the Vim ones;
  • Tokyo Night: the VS Code theme;
  • Kanagawa: the Neovim theme.

2.3 The contrast

Each theme is checked for contrast by WCAG's formula. Text, links, the selection, the mode line and the search highlight read at 4.5:1 or more. Comments, line numbers, the syntax colours and the smaller marks read at 3:1 or more.

A colour that falls short in its project's palette is moved toward white or black, no further than it needs, so that it keeps its hue.

Comments are the exception. Seven projects set them quiet on purpose: Solarized dark and light, Tokyo Night and Tokyo Night Light, Everforest Light, One Dark and Nord. Those stay as they are, only lifted to 2.5:1 where the project's own is lower. The package's test lists them by name.

2.4 Two choices in Solarized

Solarized uses its original green (#859900), as the palette table in its repository gives it, not the brighter one the Vim port tries. Solarized's text is its emphasised colour (base1 on dark, base01 on light), since its body colour reads at only 4.1:1.

2.5 Your own changes

Any set-face line in the init file stays on top of the theme. To see which faces exist and how a theme draws them, use M-x list-faces.

Choosing and pairing themes

The editor's commands and settings that choose and pair themes.

The package adds themes and nothing else: it has no command or setting of its own. These belong to Tuatara and work with every theme, these included. Tuatara's own manual describes them in the chapter on packages.

4.1 Choosing a theme

M-x load-theme lists every theme, with a description beside each, and applies the one you choose. Called from the init file as (load-theme 'NAME), it applies the theme at every start.

4.2 Pairing a light and a dark theme

M-x toggle-light-dark-theme switches between a light and a dark theme. The settings name the pair. If the window follows the desktop's light or dark style, these are the two it switches between: *light-theme* and *dark-theme*, which are Tuatara's own two themes until you set them.

(setf *dark-theme* 'tokyo-night
      *light-theme* 'tokyo-night-light)
